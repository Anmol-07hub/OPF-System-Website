# OPF System Website

Free static download website for OPF System.

## Publish with GitHub Pages

1. Create a PUBLIC GitHub repository named `OPF-System-Website`.
2. Upload `index.html`, `styles.css`, `robots.txt`, and `sitemap.xml` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. The expected site URL is:
   `https://anmol-07hub.github.io/OPF-System-Website/`

The Download buttons currently point to:
`https://github.com/Anmol-07hub/OPF-System-Updates/releases`

After the v3.0.0 installer is uploaded as a GitHub Release asset, the button can be changed to a direct release download URL.
